# Career Coach Pro - Your Personal Career Agency

A Python tool that acts as your personal career consultant. Whether you're a fresh graduate, career pivoter, or working professional looking to level up, this tool gives you professional guidance on everything from LinkedIn optimization to interview preparation.

## Features

- **LinkedIn Profile Optimizer** - Headline generator, About section writer, experience reframer, skills advisor, and post ideas
- **CV / Resume Guidance** - Ideal structure, tailored examples, and common mistakes to avoid
- **Cover Letter Tips** - The 4-paragraph formula with templates and do's/don'ts
- **Job Market Insights** - Salary ranges, top cities, demand levels, certifications, and job titles for 12 career fields
- **Interview Preparation** - Common questions with answer templates, behavioural question prep using STAR method, and pre-interview checklist
- **Skills Roadmap** - Personalized 90-day learning plan with progress tracking
- **Save to File** - Export your entire career plan as a text file

## Supported Career Fields

Data Analytics, AI/Machine Learning, Business Intelligence, Digital Marketing, Product Management, UX Design/Research, Software Development, Project Management, Finance/Accounting, Supply Chain/Operations, Human Resources, Sales/Business Development

## How to Run

1. Make sure Python 3 is installed
2. Clone this repository:
   ```
   git clone https://github.com/ayeshashimu13/linkedin-career-coach.git
   ```
3. Navigate to the folder:
   ```
   cd linkedin-career-coach
   ```
4. Run the program:
   ```
   python3 linkedin_career_coach.py
   ```
5. Start with option 1 to tell the tool about yourself!
